# Salvall Prototypes

Professional website templates showcasing three different business types. This project demonstrates modern, responsive single-page applications (SPAs) built with React and TypeScript.

## 🎨 Featured Prototypes

### 1. Construction Company - BuildPro Construction
- **Theme**: Professional blue/gray
- **Features**: Hero section, company info with statistics, project gallery, contact form
- **Target Audience**: Construction and building companies
- **Route**: `/construction`

### 2. Café - Cozy Corner Café
- **Theme**: Warm brown/cream tones
- **Features**: Inviting hero, menu specialties, café gallery, contact with social media
- **Target Audience**: Coffee shops and cafés
- **Route**: `/cafe`

### 3. Pizzeria - Bella Napoli Pizzeria
- **Theme**: Red/Italian-inspired
- **Features**: Appetizing hero, featured pizzas menu, food gallery, contact with delivery info
- **Target Audience**: Pizzerias and Italian restaurants
- **Route**: `/pizzeria`

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/johan-persson-cap/salvall-prototypes.git
cd salvall-prototypes
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 📝 Available Scripts

### `npm start`
Runs the app in development mode. The page will reload if you make edits.

### `npm test`
Launches the test runner in interactive watch mode.

### `npm run build`
Builds the app for production to the `build` folder.

## 📱 Responsive Design

All prototypes are fully responsive and optimized for:
- 📱 Mobile devices (320px and up)
- 📱 Tablets (768px and up)
- 💻 Desktops (1024px and up)

## 🎨 Customization

Each prototype is self-contained in its own component folder:
- `src/components/Construction/` - Construction company prototype
- `src/components/Cafe/` - Café prototype
- `src/components/Pizzeria/` - Pizzeria prototype

You can easily customize colors, content, and images by editing the respective `.tsx` and `.css` files.
